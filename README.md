# Coleção Java Spring

Repositório dedicado aos projetos desenvolvidos durante estudos da coleção Java Spring na plataforma [DevSuperior](https://devsuperior.com.br/colecao-java-spring), com foco no desenvolvimento backend utilizando Java e Spring Boot.

Os projetos estão organizados por curso e abrangem desde os fundamentos do ecossistema Spring até tópicos avançados de arquitetura, segurança, testes automatizados, mensageria e implantação em nuvem.

## Java Spring Professional

Estudo dos fundamentos do Spring e desenvolvimento de APIs REST, com foco na estruturação de aplicações, persistência de dados, segurança e implantação.

### Conteúdos estudados

- Componentes e injeção de dependência
- Modelo de Domínio e ORM
- API REST, camadas, CRUD, exceções, validações
- JPA, consultas SQL e JPQL
- Login e controle de acesso
- Homologação e implantação com CI/CD

### Principais tecnologias

Java, Spring Boot, Spring Data JPA, Hibernate, Spring Security, JWT, OAuth2, SQL, H2, PostgreSQL, Docker, Postman e Railway

## Java Spring Expert

Aprofundamento na construção de aplicações Spring Boot, com foco em testes automatizados, qualidade de código, segurança, validação e implementação de casos de uso.

### Conteúdos estudados

- Testes automatizados
- Validação e segurança
- Cobertura de código com Jacoco
- Testes de API com MockMvc e RestAssured

### Principais tecnologias

Java, Spring Boot, Spring Data JPA, Hibernate, JUnit, Mockito, MockMvc, RestAssured, JaCoCo, Spring Security, OAuth2, JWT, Bean Validation e SMTP

## Objetivo do repositório

Este repositório reúne projetos práticos desenvolvidos ao longo da minha formação em Java e Spring, registrando minha evolução no desenvolvimento backend e servindo como referência para estudos, revisões e experimentação de diferentes tecnologias e abordagens.

Os conteúdos estão organizados por curso para facilitar a navegação entre os projetos e os conceitos trabalhados em cada etapa.
